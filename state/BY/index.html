Germany uses a mixed-member proportional system

First vote: you pick a candidate for your local constituency. Whoever gets the most votes there wins it, and the first vote map shows exactly that (candidate with most votes wins, first past the post).
Second vote: you pick a party. It decides how many seats each party gets in total, so it is the vote that counts most. A constituency winner only gets a seat if their party's second votes cover it (proportional representation).
